# Мероприятия на главной

Автономный блок по композиции `partners/#partner-community`: две фотокарточки, одна колонка до768px, заголовок, вводный текст и ссылка на архив. Контент — два последних события из `pages/events/data/events.json`. Исходные названия, даты и ссылки сохранены; фотографии — оригиналы тех же изображений из официального хранилища.

- `index.html` — самостоятельное превью, работает без JavaScript.
- `block.html` + `block.css` + `assets/` — раздельная вставка; `fonts.css` нужен, если на сайте ещё не подключён Tilda Sans.
- `paste.html` — один HTML-фрагмент со встроенными фотографиями и шрифтами.
- `content.json`, `manifest.json` — данные, происхождение и SHA-256.

На главной секция стоит перед статьями. Ссылка «Все мероприятия» ведёт в новый GitHub-каталог; при переносе на боевой домен заменить `/barn-estate-homepage-clone/media/meropriyatiya/` на `/media/meropriyatiya/`. Детальные публикации ведут на действующий barn-estate.ru.

Дизайн: текущие `partners/assets/program.css` и `kit.css`, UI-кит главной v1.0.3. Новых зависимостей нет; HyperUI/Swiper из frontend-памятки не требуются. Главная добавляет секцию после штатной гидратации через существующий `home-content.js`; архивный HTML и Nuxt-сборка не меняются.

Сборка: `node source/tools/home-events.cjs --pack` из папки главной. Для новых событий сначала подготовить соответствующие фотографии и дополнить `source/content/events-photos.json`; сборка сообщит об отсутствующем фото.

Рабочий источник и сборщик: [barnes-sites](https://github.com/daniilterekh-prog/barnes-sites/tree/main/main-site/pages/home/exact-2026-10-21/source). Эта папка — канонический переносимый пакет и две фотографии; для обновления использовать указанный сборщик.

09.11.2026: «Как прошло мероприятие» использует текстовую роль ссылки новостей главной: Tilda Sans400,14px/16.8px на всех ширинах, обычный регистр, без разрядки.
