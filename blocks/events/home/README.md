# Мероприятия главной ·1.1.0

Шесть последних событий из общего каталога: две карточки на компьютере и одна до768px. Даты — белые плашки на фото; заголовки — как в каталоге мероприятий. Надпись «Как прошло мероприятие» полностью повторяет «Читать подробнее» из новостей: чёрная, подчёркнутая, без стрелки. Кликабельна вся карточка.

Под карточками — стрелки слева, «Все мероприятия» справа в одной строке. Круглые кнопки и SVG взяты из текущих новостей главной. Стрелки листают по два события на компьютере и по одному на телефоне, отключаются на границах. Можно свайпать, пользоваться горизонтальной прокруткой и клавишами ←/→, Home/End при фокусе на треке. За пределами видимой области ссылки исключены из Tab через inert; диапазон объявляется только для скринридера. С reduced-motion кнопки переключают сразу.

- `index.html` — самостоятельное превью.
- `block.html`, `block.css`, `block.js`, `assets/` — пакет для вставки; скрипт подключать с defer после разметки. `fonts.css` нужен, если Tilda Sans ещё не подключён.
- `paste.html` — один фрагмент со встроенными стилями, шрифтами, фото и контроллером.
- `content.json`, `manifest.json` — данные, происхождение и SHA-256. На страницу вставлять один экземпляр секции.

Без JavaScript все шесть карточек доступны нативной горизонтальной прокруткой; неработающие кнопки скрыты. Автопрокрутки нет. Секция главной встраивается после гидратации через существующий home-content.js. Общие компоненты сайта и финальные узлы не меняются.

Источник композиции — `partners/#partner-community`, стрелок/ссылки — текущие новости главной; UI-кит1.0.5. В строке слайдеров frontend-памятки рассмотрен Swiper: нативный scroll-snap покрывает задачу, новая библиотека не добавлена.

Сборка из папки главной: `node source/tools/home-events.cjs --pack`. Контент берётся из `pages/events/data/events.json`, фотографии1600px — из оригиналов тех же официальных файлов; источники/контрольные суммы в `source/content/events-photos.json`. Для новых событий сначала подготовить фото и метаданные.
