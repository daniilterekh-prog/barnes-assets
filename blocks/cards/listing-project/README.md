# Карточка ЖК

Адрес выводится отдельной строкой над названием: 15px/400/1.35, цвет #65717A — как адрес карточки лота на Курортной. Сохраняй адрес из данных. В демо «Сочи, ул. Шоссейная, 9Б» — адрес офиса продаж на объекте с сайта https://grand.marine-garden-sochi.ru/ (проверено 12.10.2026).

Самостоятельный вариант карточки новостройки: изображение, локация, срок сдачи, спальни, цена и две компактные кнопки. Подключите `styles.css`, вставьте `fragment.html` и замените контент/ссылки без изменения классов контракта.
