# LaunchCard — старт продаж

[Превью](index.html) · [HTML](fragment.html) · [CSS](styles.css) · [Контракт](../../../ui-kit/components/launch-card.md)

Самостоятельная имиджевая карточка для слайдера «Старты продаж». Карточка не зависит от Nuxt или исходной страницы; изображение хранится в `_assets`.

При интеграции замените URL, тексты, цену, регион и изображение. Геометрию, градиент, типографику и focus-состояния сохраняйте.
