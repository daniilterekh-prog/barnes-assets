Эталон узла первой степени. Источник: `kurortnaya`, commit `62aee9e62e2fae669028433ffe411e2f18a01d84`.

- `fragment.html` — desktop/tablet; `mobile.html` — до 540 px.
- `index.html` — самостоятельное превью.
- `styles.css` — подключение общего слоя; копируйте `_shared` вместе с блоком.

Тексты, изображения, ссылки, телефоны и ID якорей заменяются под новый узел. Полная инструкция: [общий README](../README.md).

## Старты продаж по блоку выбора главной ·02.11.2026

Источник компоновки — `.barnes-choice` утверждённой главной `exact-2026-10-21/`. Вкладки и выпадающий выбор направления отсутствуют. Курортные данные четырёх проектов, фото, цены, локации и сроки сдачи сохранены. В HTML только оригиналы; клоны создаются Splide при монтировании, захваченных inline-transform нет.

Карточка500px на desktop/tablet,410px до540px; соседние карточки84% высоты, ширина текста100% карточки. Типографика имени31/400 (29px до767px), цены21/400 (20px до359px), локации14/500 (13px до540px), белые на фотографии; геометрия/шрифты прямо сверяются с главной. Стрелки768px+ под карточками справа, ниже CTA «Смотреть все объекты» к #catalog-grid; на телефоне свайп и точки. Сетка до1920px, поля общие с другими блоками.

Splide скопирован из существующего автономного блока главной `04-recommendations/block.js`, MIT-лицензия рядом с локальными ассетами (в canonical `_shared/SPLIDE-LICENSE.txt`). Установка пакетов не нужна. Runtime: `BarnEstateStartSales.mount(section)` возвращает cleanup, повторный mount идемпотентен. Для страницы запускается автоматически, для переносимых блоков — через initNode. Избранное делегировано и синхронизируется с клонами и localStorage; обычный клик ведёт по сохранённой ссылке проекта.

Проверки: tools/verify-start-sales.cjs,10ширин320–3840px; сравнение размеров карточек/контейнеров и шрифтов с главной, навигация и избранное. Дополнительно touch/клавиатура/resize/reduced-motion и превью блоков. H1/FAQ и другие секции не меняются.
