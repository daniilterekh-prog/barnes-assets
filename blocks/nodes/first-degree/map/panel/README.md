# Полноэкранная панель объектов — preview 1.0

Источник интерфейса и публичного каталога: https://front.barnes.vsavr.ru/kurortnaya/, 12.10.2026. Рабочая интеграция: `barn-estate-homepage-clone/kurortnaya`.

Копируй эту папку целиком. После монтирования основного блока карты подключи обычные scripts последовательно: `map-projects.js`, затем `map-fullscreen.js`. Скрипт сам подключит соседний CSS. На странице должны существовать `.catalog-projects-map` и кнопка `.catalog-projects-map__fullscreen`. Не подключай два экземпляра панели на одну страницу. Экспорт основного блока и `onMap` не заменены автоматически.

`window.BarnesMapProjects` — заменяемый адаптер массива `{name, href, image, type: 'rc'|'lot', price, priceRub: number|null}`. Для новых узлов меняй данные и картинку, не используйте демо-каталог как актуальную базу. В текущем снимке 32 ЖК, отдельных лотов нет. Неизвестная цена исключается при активной границе цены и сортируется в конце.

Desktop: левая панель 420 px, остальное — подложка. Mobile до 540 px: нижняя панель, раскрытие до 85dvh, кнопка/фокус поиска открывает список. Поиск по названию, тип, цена, дополнительные настройки сортировки, сброс. Закрытие крестиком/Escape, блокировка фонового скролла, inert фон, trap фокуса и возврат к исходной кнопке.

**Статус: согласованный визуальный прототип, не интерактивная карта.** `map-preview.png` — статичный снимок Яндекс с атрибуцией, не Leaflet/OSM. Маркеры не обновляются при фильтрации. Zoom/геопоиск/API нет. Для боевой карты требуется отдельный Яндекс-адаптер. В интерфейсе есть видимая пометка о статичности.

Проверка в репозитории страницы: `scripts/verify-kurort-map.cjs`, viewport 390/1440/2560, поиск/цена/тип/сортировка/сброс/закрытие/возврат фокуса/overflow. Системные пакеты не добавлялись. Компонент изолирован `.map-browser`, hover/focus бордовый, жёлтых hover нет.
