# Общие подробные фильтры Курортной ·1.3.0

Одна светлая форма для hero/листинга/карты, по общему каталогу. В карте она открывается справа. Desktop640px, mobile≤540fullscreen; шапка24/400, группы18/400, значения18/300, chip16/400. Общий catalog-filters.css отменяет прежний dark-вариант. Форма не дублируется.

BarnesFilters.getState()/patch(fields)/reset(), события barnes:filters-open и barnes:filters-apply. Market всегда ровно new-build/secondary, reset его сохраняет. Спальни — native radio-group с подписью. Черновик, ошибка диапазонов, Escape, inert/focus trap и возврат фокуса сохранены. API каталога подключается отдельно, недостающие сведения об объектах не выдумываются.

Подключение и пути — [общий README](../README.md). Контроллеры хранятся в единственном экземпляре: внутри js/ самодостаточной страницы либо в этой папке канонической библиотеки.
