# Выпадающие быстрые фильтры Курортной

`brand-filters.js` — авторский компонент чекбоксов «Выбор BARNES» / «Эксклюзив BARNES»; сам загружает соседний CSS. Подключай после `BarnesFilters`; toolbar и карта могут появиться позднее. Компонент вставляет fieldset, синхронизирует `brandFlags` (`selection`/`exclusive`). Native Space/focus, label, touch target44px. Техническая подпись скрыта. В демонстрационном листинге брендовых данных нет, выдача не меняется; карта фильтрует по реальному `item.brandFlags`, оба признака — OR. Отсутствующие признаки не выдумывать. Итоговая раскладка 12.10.2026: mobile listing — параметры 2×2 → фильтры/сортировка → чекбоксы; desktop listing — рынок/чекбоксы/сортировка на верхней строке. Карта: параметры → сортировка → чекбоксы → сброс, шаг рядов70px. Левый край обоих чекбоксов совпадает с SVG соответствующих колонок. Reset снимает brandFlags, но не обязательный market. Проверка: `scripts/verify-kurort-brand-filters.cjs`.

Источник белого dropdown: https://front.barnes.vsavr.ru/kurortnaya/, 12.10.2026. В исходнике type/price/area; в утверждённом узле поля location/propertyTypes/price/bedrooms. Локация: Сочи/Анапа/Алтай/Архыз. Тип: апартаменты/квартира/квартира в новостройке/пентхаус, значения apartment/flat/new_build/penthouse. Цена: до50 / 50–100 / 100–200 / от200 млн ₽. Спальни: 1/2/3/более3. Есть снятие выбора.

Подключай `../_shared/source.css`, затем scripts общей папки `../filters-modal/` и этот `quick-filters.js`. Последний сам загрузит соседний CSS. Требуются четыре `.catalog-mode-filters .catalog-quick-filters__button` с `.catalog-quick-filters__caption` в порядке локация/тип/стоимость/спальни и `window.BarnesFilters.patch/getState`. Повторный вызов не создаёт второй popup. Актуальная сборка листинга сохранена рядом в `listing-mode.js` и `listing-mode.css`: скрипт работает на исходном catalog-grid с карточкой, не подключать повторно к уже собранному листингу. Все четыре быстрых поля равной ширины. Десктоп — четыре поля в ряд; планшет ≤1024 и мобильный ≤540 — 2×2. Кнопка «Все фильтры» отдельно. Для отдельной интеграции можно перенести toolbar markup/SVG из listing-mode.js без сборки карточек. Не совмещать с демонстрационным onFilter из `_shared/runtime.js`: это два альтернативных обработчика.

Выбор закрывает меню, обновляет текущую подпись и `aria-label`, общий state и событие `barnes:filters-apply`. `directions`/`propertyTypes`/`priceRanges` — массивы; `bedrooms` — отдельная строка 1/2/3/4+ или пустая. Тип синхронизируется в обе стороны с подробными фильтрами. Спальни не заменяют число комнат из исходного общего modal. Снятие/повторный выбор корректны; общий reset+apply очищает все поля. API выдачи не реализован, серверные filter-URL исходника не имитируются.

Markup/белая рамка/padding13 сохраняют dropdown из source.css. Типографика обновлена по BARNES: Tilda Sans, header17/19 px weight400, options17/19 px weight300, lineheight1.3, minheight40; 19 px от1441 px. Popup ≥220px, не шире viewport−32px; располагается около кнопки с переносом вверх при нехватке места. Button typography/SVG не меняются. Тень выключена, hover/selected только бордо #8B1D25. Один немодальный dialog с listbox/options и крестиком. Arrow/Home/End и Enter/Space, Escape/внешний клик, focus возврат. На scroll следует за кнопкой, вне viewport/resize закрывается.

Сортировка листинга и карта (тип/локация/спальни/сортировка) используют этот же popover. Native select остаются скрытыми адаптерами состояния, visible buttons `.resort-sort-trigger` / `.resort-select-trigger` синхронизируются через change. Цена карты — числовые поля, не список. В карте popover временно освобождается от фонового inert и восстанавливает его при закрытии; Escape списка не закрывает карту. Рынок new-build/secondary всегда выбран и независим от типа. Сброс сохраняет рынок.

Проверка: `scripts/verify-kurort-quick-filters.cjs` в репозитории страницы, 390/768/1440/2560; также регрессия общего modal и map. Новых зависимостей нет.
