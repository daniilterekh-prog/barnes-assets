# Проверка экспорта 1.0.0

Источник DOM: Курортная dacc3ab, Chromium, CSS viewport. Изменения исходной страницы в рамках упаковки не выполнялись.

- Сборка 390, 768, 1366, 1920, 2560 px: горизонтального переполнения не обнаружено; замеры сохранены в UI-ките.
- 2560 px: визуально просмотрен листинг, фотографии загрузились, размеры характеристик 12/16 px.
- 390 px: проверены переключение ЖК/лотов, открытие FAQ, избранное, dialog фильтра, попап заявки, закрытие и возврат фокуса.
- Карусель: кнопка next меняет активный слайд с slide01 на slide02. Из exported HTML удалён data-start-sales-bound, чтобы pagination могла подключиться заново.
- Standalone карточка старта: одна карточка, изображение загружено, нет overflow.
- Pagination после повторного подключения: третья точка активирует slide03. Все 18 папок содержат обязательные файлы, локальные src существуют; в проверенной mobile-сборке битых загруженных изображений нет.
- JavaScript runtime: node --check; diff: git diff --check.

Ограничения: карта намеренно заменена заглушкой; backend форм не подключён; реальные поиск/фильтрация/сортировка и глобальное меню передаются через callbacks. Проверка preview не подтверждает эти внешние интеграции. Переход desktop/mobile через 540 px требует remount.
