# Возврат на региональный узел

Собственная статическая ссылка для лендингов Алтая и Турции, 21.10.2026. Шрифт наследуется от проекта; тёмная прозрачная подложка, тонкая рамка, доступный фокус, reduced motion. Без библиотек и JavaScript. Рабочие исходники и точная карта страниц: приватный barnes-sites/shared/hub-return/.

Над H1 в hero:

```html
<a class="barnes-hub-return barnes-hub-return--hero" href="https://altay-preperty.ru/" hreflang="ru"><span aria-hidden="true">←</span>Все проекты Алтая</a>
```

В Турции использовать https://turkish-property.ru/ и «Все проекты в Турции». Английская подпись — «Explore projects in Turkey» с видимой пометкой RU: английский узел /en/ отсутствует. В блоке похожих проектов: модификатор `barnes-hub-return--related`, подпись «Смотреть все проекты», стрелка →.

CSS содержит совместимость с flex-порядком старых алтайских лендингов: блок похожих проектов получает order 99, после основных секций 1–16. Подключать стили после базовых стилей лендинга. На рабочих страницах CSS инлайнится для независимости от кеша/CDN.

Источник оформления — существующие hero и связанные проекты BARNES, без внешних компонентов. Каталог выбора ресурсов: https://github.com/daniilterekh-prog/codex-knowledge-base/blob/main/knowledge/frontend-free-resources.md.

Для существующего Tilda hero «Рэдиент» дополнительно подготовлен `radient-tablet.css` (601–1100 px): его фиксированная высота раньше обрезала H1 над экраном. Этот адаптер подключается только на «Рэдиенте», чтобы ссылка и заголовок помещались в первом блоке.
