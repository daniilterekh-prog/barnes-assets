# Контактный CTA — амбассадоры

Форма на фото, компактные каналы и эксперт справа.

[Превью](index.html) · [HTML](fragment.html) · [CSS](styles.css) · [Паспорт](block.json) · [Общая инструкция](../../partners/README.md)

Источник: /for-partners/, commit `8caa88ffc380031461cd2875f0bf733ce147864e`. Версионный эталон, не автоматическая замена блоков действующих страниц.

Скопируйте фрагмент, стили и зависимости из block.json. Сохраните классы, data-v-*, data-source-id и scope `.barnes-template`. Вызывайте initBlock после вставки в DOM. Меняйте контент, изображения и ссылки под новую страницу; данные клиентов не должны быть зашиты в шаблон.


Формы и кнопки не отправляют данные сами. Передайте onRequest/onSubmit и подключите backend. Preview запрещает отправку. Блоки request-modal/floating-expert фиксируются поверх страницы по своему назначению. При вставке нескольких экземпляров ID/ARIA уникализируются; CSS опирается на data-source-id.
