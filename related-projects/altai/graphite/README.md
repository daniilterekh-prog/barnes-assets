# Панорама Алтая — графитовая палитра

21.10.2026 пользователь попросил убрать зелёный фон, который не совпадал с курортными лендингами. Фон теперь `var(--dark-section, #161616)`: использует цвет тёмных секций проекта, с нейтральным графитовым fallback. Зеленоватые оттенки текста, наведения стрелок и затемнения карточек заменены нейтральными. Шрифты наследуются от страницы; сетка, фотографии и поведение исходного варианта 2 сохранены.

Собственный HTML/CSS/JS без новых библиотек. Источник — действующий компонент `barnes-sites/shared/altai-related-projects`, фото — `../20261019/`, закреплённые на commit 4aa6ef0. [Каталог frontend-ресурсов](https://github.com/daniilterekh-prog/codex-knowledge-base/blob/main/knowledge/frontend-free-resources.md).

- `styles.css` — изолированные стили.
- `script.js` — существующая карусель, клавиатура и reduced motion.
- `fragment.html` — пример каталога со всеми девятью проектами. На странице проекта нужно исключить собственную карточку и ссылку; точные рабочие версии генерируются в приватном barnes-sites.

Подключить CSS после стилей лендинга, вставить fragment, подключить script с defer. Секция с ID related-projects должна быть единственной на странице. Не вставлять второй экземпляр поверх существующего блока. На ISPmanager используется локальный CSS с версией `20261021-graphite`; в Тильде — inline CSS в существующем T123.

Публикация отслеживается отдельно в barnes-sites/docs/altai-related-palette-2026-10-21. Наличие файлов здесь не подтверждает обновление платформы.
