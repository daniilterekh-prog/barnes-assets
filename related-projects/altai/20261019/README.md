# Лесная панорама: другие проекты Алтая

Оптимизированные изображения для утверждённого блока похожих проектов на 9 алтайских лендингах BARNES и общем каталоге. 19 октября 2026. Исходные изображения уже опубликованы на соответствующих лендингах; новые изображения не генерировались.

Источники: Белогорье — assets/img/belogorie-hero-new.webp; Бирюзовая Катунь — assets/img/biryuzovaya-katun-hero-summer.webp; Кедры — assets/optimized/hero-wide-retina.webp. Грушевый цвет, ЗаГорье, Карлуу, Медвежий угол, Рэдиент, Rizalta — опубликованные фотографии из соответствующих папок канонической библиотеки barnes-assets. Точные пути и проектный код сохранены в приватном barnes-sites, shared/altai-related-projects/projects.json.

Ширина до 1400 px, WebP. Шерегеш, Сочи и Архыз в подборку не входят.
