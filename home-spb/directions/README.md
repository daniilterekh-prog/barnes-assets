# Изображения направлений главной СПб

10.11.2026 по поручению пользователя заменены изображения вторичной и коммерческой недвижимости, для новостроек выбран ЛДМ.

- `secondary-original.png` / `secondary.webp` — светлая гостиная в петербургском историческом доме, новая генерация встроенным image_gen.
- `commercial-original.png` / `commercial.webp` — иллюстративный фасад премиального бизнес-центра, новая генерация встроенным image_gen.
- `ldm-original.jpg` / `ldm.webp` — официальный дневной проектный рендер ЛДМ с сити-виллами, источник AURIX. Не фотография построенного дома.

[Точные промпты](prompts.json) · [Происхождение, размеры и SHA-256](sources.json). Сгенерированные изображения используются только для карточек направлений, не подставлены вместо фотографий конкретных лотов. Все восемь зарубежных/курортных рекомендаций и13 записей СПб сохранены.

WebP получены установленным Sharp из Codex Toolkit, до1600px без увеличения. Оригиналы сохранены. Никакие старые ассеты не перезаписывались.
