# Каталог главной СПб

Проверено10.11.2026. По прямому поручению пользователя проекты, лоты и фотографии взяты с https://barnestate-spb.ru/. Это источник агентского каталога для данной задачи; не независимая проверка застройщиком.

Четыре жилых проекта: «Фонтанка130», «Коллекционер», LDM, «Визионер». Девять лотов: городская, загородная и коммерческая недвижимость Петербурга и области. [Точные страницы, URL изображений, значения источника и контрольные суммы](sources.json).

`*-original.*` — полученные изображения без ретуши и генерации; `*.webp` — оптимизация установленным Sharp через Codex Toolkit, до1920px для проектов и1280px для лотов без увеличения разрешения. Исходные водяные знаки сохранены. Нулевая/отсутствующая цена в источнике не считается бесплатным объектом: в странице используется «Цена по запросу».

Цены и наличие требуют актуализации перед боевым запуском. Числа отражают публичный каталог на дату проверки. HTML-архивы сайта не копировались.
