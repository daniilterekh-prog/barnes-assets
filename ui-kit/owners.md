Обновлено 2026-10-08. Каноническая библиотека — `daniilterekh-prog/barnes-assets`. Источник: утверждённые аренда и продажа из `barn-estate-homepage-clone`, commit `43612ab`. Не заменяет правила главной страницы автоматически.

## Основы

- Tilda Sans; заголовки и lead — 300, названия карточек и кнопки — 400.
- Основной текст #1e1e1e, описания #4f4d49, muted #656462; акцент #8b1d25; белый фон, поверхность #f1f1f1, линия #e4e4e4.
- Радиус прямоугольников 1px. Круглые портреты и круглые стрелки — отдельный компонент, не правило для всех шейпов.
- Контейнер 1920px; на широких экранах внутренние направляющие 100px. Full-bleed фон не должен расширять текстовый контейнер.
- Медиа-превью сгенерированы: не выдавать за реальные объекты или офис. Портрет модального окна — AI-композит по настоящему фото Руслана; оригинал остаётся в исходном репозитории.

## Контракты компонентов

### Стратегия презентации

2px между изображениями. White/overlay/hover как в исходнике; описание проявляется при hover и клавиатурном фокусе. Аренда: четыре темы и featured-карточка; продажа: шесть тем. Не переносить подписи автоматически. Новая серия архитектурной премиальности — источник `shared/assets/presentation-v3`.

### Единая команда

Название и описание разделены strong/span. Название #1e1e1e, описание #4f4d49; при бордовом hover оба белые. В аренде пять карточек, в продаже одиннадцать. Тексты вариантов не смешивать.

### Механика / scroll narrative

Desktop grid .86fr / 1.14fr, gap clamp(52px,6vw,116px); sticky aside. До 900px — последовательное чтение. В portable adapter активная строка определяется прокруткой, а reduced-motion оставляет контент доступным. Сравнивать анимацию с целевой страницей, не считать экспорт исходным Vue-кодом.

### Почему собственники выбирают BARNES

Белая панорама, 4 вкладки. Номера: квадрат 42px desktop / 36px mobile, радиус 1px, активный бордовый. Название справа с gap16/10. Desktop четыре колонки, до1000px две, до360px одна. Панель: бордовая левая линия2px, padding32/32/36, mobile24/20. Кнопка под левым заголовком. Все четыре текcта измеряются для одинаковой высоты. Клавиши Left/Right/Home/End, roving tabindex. CTA «Консультация эксперта»; контекст rent/sale сохраняется.

### Центральная и нижняя формы

Это разные шаблоны, не объединять автоматически. Нижний CTA продажи содержит круглое фото Руслана; текст справа не капсом. Input-типографику сверять с соответствующей центральной формой. Поля имеют labels/aria-label, keyboard focus, сообщения ошибок. API и согласия проверяются отдельно перед запуском.

### Модальная заявка

Desktop текст и поля слева, единый портрет справа; max-width940, scroll при нехватке высоты. Портрет `modal-ruslan-organic.webp`, object-position center top. Mobile верхний портрет240px, затем поля; голова не обрезается. Close/Escape, ограничение фокуса внутри и возвращение фокуса кнопке. Заголовок/описание зависят от аренды или продажи. Превью ничего не отправляет.

## Безопасное переиспользование

Копировать вариант блока и ресурсы `_shared`/`_assets`, подключить initBlock. Через onRequest подключать текущую форму сайта, через onSubmit — реальный API. CSS ограничен `.barnes-template`; data-v атрибуты оставлены как селекторы, но Vue не нужен. initBlock уникализирует ID и ARIA-ссылки. Контентные якоря и навигационные ссылки адаптировать вручную.

Не изменять утверждённые страницы при обновлении библиотеки без отдельного задания. Новая версия компонента — отдельный commit, источник и проверка в block.json/verification.json. Минимум проверки: 390,768,1440,1920,2560px; формы, вкладки, слайдер, keyboard, reduced-motion, битые ассеты. Превью noindex, публикационные страницы сохраняют свою SEO-разметку и один H1.
