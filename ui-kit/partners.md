## Кнопки и каналы связи

### ActionButton (основной CTA)

Высота70px desktop/tablet;58px до540px. Шрифт17px base/19px wide/18px mobile,400. Радиус1px. Не растягивать «Отправить заявку» в направлениях: width fit-content, слева. SVG в hero26px desktop,28px wide,24px mobile — page-specific оптическая настройка, не размер всех иконок.

### ContactSelector / compact

Последнее утверждение пользователя: видимая высота **35px desktop/tablet,29px mobile** — ровно половина предыдущего action-размера. Шрифт17/19/18px,400, сохранён. SVG18px desktop/tablet,22px mobile, включая MAX. Радиус1px. Четыре колонки от1280, две ниже; gap12px по горизонтали,16px по вертикали. Невидимая pointer-area44px: inset4.5px desktop/7.5px mobile, соседние области не пересекаются. Focus должен быть видимым. Семантика: role=group и нативные buttons с aria-pressed; выбран ровно один канал.

Это **не** ActionButton: нельзя применять35/29px к основной кнопке отправки, hero или footer action. При необходимости полноразмерного ContactAction используйте базовый70/58px.

## Фотокарточки

- Преимущества: одинаковый верх номера и заголовка, tabular-nums; текст описания скрыт в покое. Фото:12% постоянного затемнения,68% hover/focus/reveal. Высота540px desktop/460px до1024, не меняется от раскрытия. На touch — кнопка+/−, aria-expanded/aria-controls. Карусель:3/2/1 видимых карточки, стрелки, Home/End и drag. Art de vivre последним — правило контента источника, не любой карусели.
- Условия: фото и заголовок в покое; описание + затемнение72% при hover/focus/tap. Min-height360px desktop/260px compact, радиус карточки4px; радиус кнопок1px. Подписи и проценты не переносить на другой продукт без подтверждения.
- Переход240ms; `prefers-reduced-motion` отключает анимацию. На клавиатуре нельзя требовать мышь для чтения описания.

## Переключаемые направления

Единый порядок «подпись сверху → значение снизу» в бюджете, показателях и комиссии. Цифры обеих колонок выровнены; резерв подписи metrics56.32px desktop/67.2px до1024, gap12px. Desktop: фото слева, контент справа; низ фото до низа кнопки. Фиксированная сетка сохраняет Y кнопки и размеры фото во всех7 категориях. До900 — select и одна колонка; фото320px, до540 —290px.

Крупная бордовая комиссия48/52.8px,400; negotiated-состояние22/30.8px. «Условия оговариваются» вместо выдуманного процента. Все цены, комиссии, страны и объёмы предложения — данные конкретной страницы, не дизайн-токены.

## ContactCTA / экспертная форма

Full-bleed декоративный фон, тёмный градиент для белого текста. Основная форма слева, экспертная карточка справа; на узком mobile — компактная строка эксперта. У карточки radius1px, border1px, padding40px desktop/32px tablet, gap24px. Круглый портрет остаётся круглым; прямоугольные CTA не получают pill-radius.

Фон партнёрства — generated illustration, не конкретный объект. Портрет — пользовательский, не AI. Не переносить портрет и должность на другую команду автоматически. Шкала полей по базовому киту20/18/17px,300; старые reference-снимки должны проверяться при адаптации к новой странице.

## Поведение / интеграция

- FAQ: button + aria-expanded/aria-controls; открытый ответ доступен клавиатуре.
- Modal: open/close, Escape, удержание Tab, возврат фокуса; направление передаётся отдельными полями. Backend не входит в UI-компонент.
- Hero/sticky/header: один H1, реальные якоря, второй хедер появляется после hero, не дублирует scrolled-framework header.
- Newsletter: не показывать успешную доставку, пока сервис не подключён.
- При нескольких экземплярах блоков — уникальные ID и ARIA; CSS scope, никаких глобальных document.querySelector для локального состояния.

## Как вносить новые правила

Указать компонент, breakpoint, роль, источник и дату утверждения. Дополнение должно быть узким: compact-вариант не ломает base. После изменения текстов/числа карточек повторить responsive/keyboard QA. Preview noindex — библиотека не должна дублировать SEO посадочных страниц.
