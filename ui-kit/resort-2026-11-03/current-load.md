# Загрузка текущей версии без старой панели

Причина: исходный page-HTML содержал старые кнопки («Общая площадь», «Не выбрано»), затем listing-mode.js и catalog-filters.js перестраивали их. CSS интерфейса также загружался после начала показа страницы; в блоках сохранялись разные версии URL.

Исправление: текущий листинг и обе карточки находятся в page-desktop.html/page-mobile.html и отдельных fragment.html/mobile.html. Удалён listing-mode.js, legacy-ветка сборки в catalog-filters.js, прежние правила нижних линий и скрытия списка до JS. Начальные стили подключены в head; runtime только привязывает действия. Статические чекбоксы и динамические чекбоксы карты подключаются одним контроллером, один раз. Общий cache-version всех CSS/JS:20261103-clean-load-18.

Проверка: исходники desktop/mobile без JS, медленный runtime, повторная загрузка, единственность toolbar/dropdown/checkbox-групп и CSS, изоляция рынков, флаги. Отдельно проверены карта и библиотечные превью. Внешние библиотеки не добавлены.

Сохранены H1/FAQ, герой, данные карточек, геометрия текущих фильтров, одна обязательная категория рынка и покупка без аренды. Карта остаётся локальным снимком Яндекс.

Исходное изменение страницы:e5c3ad3. [Проверка страницы](current-load-2026-11-03.json), [полная карта](current-load-map-2026-11-03.json), [отдельная карта библиотеки](current-load-map-standalone-2026-11-03.json).
