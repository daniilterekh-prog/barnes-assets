# Подборки, карта и сортировка ·1.5.2

Запрос пользователя03.11.2026: «Выбор BARN Estate» и exclusive должны находиться на одной строке с картой и сортировкой. Дополнительное уточнение: видимая подпись второй подборки — строго `exclusive`.

Причина прежней раскладки: fieldset подборок находился в отдельном `.catalog-collections-row`; на мобильном дополнительное правило display:contents разносило кнопку карты и сортировку по разным строкам.

Исправление: fieldset перенесён в `.catalog-result-summary` в исходниках desktop/mobile и отдельных блоках. При ширине≥768px оба checkbox, карта и сортировка имеют общий вертикальный центр; количество результатов располагается над ними. На телефоне подборки занимают первую строку, карта и сортировка — следующую, без наложения и горизонтального переполнения. Старое мобильное правило с разными grid-row удалено. Fallback-контроллер создаёт подборки в том же месте; при штатной загрузке они уже находятся в HTML.

Подпись `exclusive` заменена в статическом листинге, генерируемых checkbox карты и подписи активного фильтра. Ключ `brandFlags: exclusive` сохранён: данные и состояние фильтров не переименовываются. Общие Tilda Sans, бордовый цвет, SVG, обязательный рынок и покупка без аренды сохранены. Компоненты главной не копировались; дополнительных библиотек нет. Для CSS использован существующий стек; строка HyperUI в frontend-памятке рассмотрена, установка не требуется.

Проверки: `tools/verify-listing-controls-row.cjs` —11размеров320–3840px, общий центр, отсутствие наложений, оба checkbox и их синхронизация с полной картой, новая подпись, сброс с сохранением рынка и сортировка. `verify-catalog-filter-blocks.cjs` —12сценариев страницы/канонических listing/hero/map. Дополнительно четыре проверки index/mobile без JavaScript подтверждают актуальный статический HTML.
