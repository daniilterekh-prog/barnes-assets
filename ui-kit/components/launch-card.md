# LaunchCard / старт продаж

Полноформатная медиакарточка стартов продаж. Актуальный узловой вариант: `blocks/nodes/first-degree/card-start-sales/`; старый `blocks/cards/start-sales/` сохранён отдельно.

- Высота `438px`, максимальная ширина `520px`, radius `1px`.
- Заголовок `31/34.72px`, mobile `29/32.48px`, weight `400`.
- Цена `21/26.25px`; регион над названием `14/16.8px` desktop, `13/15.6px` mobile, weight `500`, uppercase, отступ 10 / 9 px.
- Название ближе к разделителю: 18px desktop / 16px mobile.
- Нижний градиент сохраняет контраст текста; срок старта выводится отдельной белой меткой.
- Вся карточка — одна ссылка; избранное остаётся отдельной кнопкой с `aria-pressed`.
