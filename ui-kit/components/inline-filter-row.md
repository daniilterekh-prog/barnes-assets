# InlineFilterRow

Строка фильтров каталога с нижними линиями.

Карта на desktop и mobile: быстрые поля → сортировка → подборки BARNES → сброс, одинаково в DOM и CSS. Label чекбоксов в карте58px с padding-top4px; gap12px и шаг центров70px соответствуют соседним рядам полей. Геометрия checkbox20px и label листинга44px не изменяется.

Оба checkbox подборок выровнены с SVG соответствующих колонок: mobile в листинге и карте (gap12/16px), desktop в карте (gap16px); две равные колонки, padding-inline-start8px у label, допуск1px. В десктопной карте подборки стоят после сортировки.

Рынок обязателен: один активный вариант «Новостройки / Вторичка», default `new-build`. Повторный клик не снимает выбор; reset/apply сохраняют рынок. Единый `BarnesFilters.market` синхронизирует карту и листинг. Записи без `item.market` не включаются в выдачу карты; разные рынки никогда не объединяются. Стадия строительства не определяется этим UI-параметром.

От1025px рынок, чекбоксы и сортировка делят первый ряд toolbar (колонки1/2/3); быстрые фильтры во втором ряду. На планшете541–1024px чекбоксы и сортировка делят третий ряд toolbar: чекбоксы в колонке1 с выравниванием вправо непосредственно перед сортировкой, сортировка в колонке2 справа, промежуток20px, выравнивание по центру. Mobile≤540px сохраняет перенос: чекбоксы row4, сортировка и подробные фильтры row3.

Дополнительные подборки: два независимых нативных checkbox «Выбор BARNES» / «Эксклюзив BARNES» в подписанном fieldset, 17px (wide19px) / weight300, ink #4F4D49. Box20px, radius1px, border #767470, checked/focus/hover только #8B1D25, focus offset3px; label minheight44px, gap10px. Строка переносится на mobile, без растягивания. Общий state `brandFlags=['selection','exclusive']`; одновременный выбор — OR. Переносимый компонент: `blocks/nodes/first-degree/quick-filter-dropdowns/brand-filters.js/css`. Техническая подпись при выборе не выводится. Отсутствующие данные не подменяются выдуманными признаками. Чекбоксы сразу под быстрыми фильтрами, margin-top8px (mobile7px) компенсирует разную высоту контролов. На планшете видимый текстовый интервал равен интервалу рынок–первый ряд фильтров (допуск1px). Mobile: чекбоксы row4, сортировка/подробные фильтры row3.

Chevron полей и сортировки на всех ширинах: 10×10px, две границы 1px #4F4D49, rotate(45deg). Старый SVG-background select отключён; используется один CSS-chevron без дублирования.

- Текст `17px` desktop/mobile, `19px` wide от 1441px, weight `300`, цвет `#4F4D49`.
- Приглушённый текст `#656462`, линия `#E4E4E4`, активный бордовый `#8B1D25`.
- Локация, стоимость и спальни равной длины; стрелка не перекрывает текст.
- Focus/hover только бордовые, без золотого контура.
- На mobile локация сверху, стоимость/спальни рядом, затем фильтры слева и сортировка справа; горизонтальной прокрутки нет. Размер/цвет/толщина chevron у сортировки такие же, как у полей.
- Актуальное превью: `blocks/nodes/first-degree/listing/`, полный контракт: [FirstDegreeNode](../first-degree.md).
