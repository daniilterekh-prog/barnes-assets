# InlineFilterRow

Строка фильтров каталога с нижними линиями.

- Текст `17px` desktop, `19px` wide, weight `400`, цвет `#4F4D49`.
- Приглушённый текст `#656462`, линия `#E4E4E4`, активный бордовый `#8B1D25`.
- Локация, стоимость и спальни равной длины; стрелка не перекрывает текст.
- Focus-within меняет линию на бордовую; focus-visible даёт золотой контур.
- На mobile поля прокручиваются горизонтально без увеличения страницы; кнопка всех фильтров находится рядом с сортировкой.
