# ListingCard / ЖК и лот

Общая оболочка с двумя контрактами данных. Эталоны: `blocks/cards/listing-project/` и `blocks/cards/listing-lot/`.

- Изображение `4:3`, максимальная ширина карточки `420px`.
- Название `22/24.64px`, mobile `20/22.4px`, weight `400`, одна строка с ellipsis.
- Подписи характеристик `10/12px`, tracking `.08em`; значения `13/16.25px`.
- Цена `26/31.2px`, mobile `24/28.8px`, weight `500`.
- ЖК: `локация / срок сдачи / спальни`. Лот: `локация / площадь / спальни` плюс ID рядом с ценой.
- Две компактные кнопки используют CardActionCompact. Избранное — кнопка `44×44px` с доступным именем.
