# ContactAction

Компактный выбор способа связи внутри CTA. Это отдельный контроль и он не наследует высоту обычной ActionButton.

- Сетка в CTA узлов первой степени: 2 равные колонки и 2 строки на всех разрешениях.
- Ширина всей группы: `width:100%; max-width:610px; box-sizing:border-box`, как у формы. Левый и правый края совпадают с полями и кнопкой отправки; группу нельзя растягивать на всю ширину контентной колонки CTA.
- Высота: `44px` desktop, `46px` mobile; gap `12px`; radius `1px`.
- Текст: `17/18.7px`, wide `19px`, mobile `18px`; weight `400`.
- Иконка: `18px` desktop, `20px` mobile.
- Внутри каждой кнопки: CSS Grid с колонками `var(--contact-icon-size) 4.8em`, gap `8px`. Иконки и начала названий выровнены вертикально в каждой колонке; вся пара центрируется внутри кнопки, текст выровнен влево. Короткое название MAX не сдвигает иконку относительно Telegram.
- Focus-visible: `2px #8B1D25`, offset `3px`; жёлтый запрещён. В узлах первой степени каналы CTA располагаются в две строки согласно экспортированному CSS, а не принудительно в четыре колонки. Выбор отражается через `aria-selected` для tab-контролов или `aria-pressed` для обычных кнопок.
