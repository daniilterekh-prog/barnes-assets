## Контракты

- Header над hero; sticky-nav после hero — якоря текущего узла, логотип, консультация/каналы. Направления не дублировать.
- InlineFilterRow: четыре равных поля «Локация / Тип / Стоимость / Спальни», SVG слева, нижние линии. Mobile/tablet: параметры 2×2; затем фильтры слева и сортировка справа; ниже чекбоксы BARNES. Desktop listing: рынок и чекбоксы на верхней строке, сортировка справа. Карта на всех ширинах: параметры → сортировка → чекбоксы → сброс. У карты шаг рядов 70px. Чекбоксы выровнены с SVG колонок, chevron одинаковы по размеру/толщине/цвету. Нет горизонтальной прокрутки и видимого слова «Сортировка».
- Все быстрые dropdown и сортировка, включая карту, используют единый .resort-quick-dropdown и адаптеры native select. Цена карты остаётся парой числовых полей. Нельзя возвращать браузерный select только для сортировки.
- Market: ровно один new-build/secondary, исходно new-build. Повторный клик/reset не снимает выбор. Тип объекта и рынок независимы; неизвестный рынок не включается в выдачу. Карта/листинг используют BarnesFilters; brandFlags selection/exclusive могут быть выбраны независимо, при обоих — OR. Метаданные не выдумывать.
- LaunchCard: регион над названием, старт отдельной меткой, затем название/разделитель/цена. Соседние слайды уменьшены, стрелки и центрирование как в исходной карусели.
- ListingProject / ListingLot: одинаковая геометрия, адрес над названием в обоих вариантах. ЖК — локация/сдача/диапазон спален; лот — локация/площадь/спальни, ID справа от цены.
- CTA central: эксперт слева, форма справа, единый full-bleed фон; не приближать портрет для заполнения фона. CTA bottom — экспертный блок плюс форма. На wide контент привязан к общей base-container, фон на весь экран.
- ContactAction: четыре канала в две строки там, где задано CSS; SVG не сжимаются. Обычные ActionButton/submit не получают размеры карточных кнопок.
- RequestModal: отдельный портрет, Escape/focus trap/возврат фокуса. Аватар mobile сохраняет верх головы, не менять object-position на center без проверки.
