# Собственники — загород: собственные изображения

13.11.2026 по поручению владельца созданы 12 отдельных иллюстраций для страницы продажи загородной недвижимости. Инструмент — встроенный image_gen; без внешних платных библиотек или новых подписок.

- `hero.webp` — дом и участок, первый экран.
- `object-assessment.webp` — оценка объекта, блок этапов.
- `market-strategy.webp` — посёлок и окружение, стратегия продажи.
- `whole-property.webp`, `completed-home.webp`, `positioning.webp`, `market-analysis.webp`, `private-viewing.webp`, `negotiation.webp` — шесть предметных карточек преимуществ.
- `country-panorama.webp` — широкая панорама для аргументов BARN Estate.
- `newsletter.webp` — самостоятельная сцена подписки.
- `property-magazine.webp` — публикация загородного объекта.

Сцены вымышленные, не фотографии конкретных лотов и не подтверждение их наличия. Фото Михаила Долгова, фирменный логотип и карточки переходов не генерировались: страница использует действующий загородный узел и общий узел «Собственникам».

Оригинальные PNG — `originals/`; WebP — рабочие оптимизированные копии (Sharp, без изменения сюжета). [Все промпты и SHA-256](PROMPTS.json).
