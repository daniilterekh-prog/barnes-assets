Оригинальные PNG сохранены в `originals/`; WebP подготовлены установленным Codex Toolkit без увеличения разрешения. Общий размер семи WebP — около1,4МБ. В `sources.json` указан точный объём каждого файла.

Все изображения — новые сгенерированные иллюстрации услуг. Они не являются фотографиями конкретных лотов, офисов или реализованных проектов. Узнаваемые реальные ЖК не изображаются. Портрет реального эксперта, фирменный логотип и фото конкретных проектов в общем меню не менялись.

В каждом блоке используется отдельный сюжет. Геометрия блока, шрифты, отступы и цвета сайта не меняются. Рабочие копии WebP находятся в `barnes-sites/main-site/pages/owner-hub/assets/editorial/` и в публичном экспорте `barn-estate-homepage-clone/sobstvenniki-uzel/assets/editorial/`.
