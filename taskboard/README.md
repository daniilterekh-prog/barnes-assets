# BARN Estate — рабочая доска

[Открыть доску](https://daniilterekh-prog.github.io/barnes-assets/taskboard/).

Вход по выбранному имени. Общие статусы, открытые срочные, даты поручений, мои задачи / поставленные мной, вопросы мне, обсуждения и отчёты о выполнении. Wiki: фронт, живой сайт, эталонное превью и ссылки на исходники. Прогресс на всю ширину с анимированным SVG-программистом; reduced motion. Изменения синхронизируются с PHP/SQLite API; текущий посетитель может менять любые задачи. Выбранное имя не удостоверяет личность. Сервер и рабочие данные хранятся отдельно от GitHub Pages.

Собственный HTML/CSS/JS без установленных библиотек. SVG-иконки [Lucide](https://github.com/lucide-icons/lucide), commit0ab9c70d88b1c8ccb07d1b0e8a12a98df6f19a59, 20символов, [ISC-лицензия](icons-LICENSE.txt). Прелоадер — [word-preloader](https://github.com/daniilterekh-prog/word-preloader), commitd7156ed4a3e4d3c4c20d935681501f6faff67f93. Клиент не содержит секретов и исходного списка задач.

19.10.2026: серверные authors-v1/discussions-v1 установлены с резервными копиями; прежние задачи, статусы, страницы, связи и история сохранены. Клиент перед публикацией проверен изолированно (11Node,62базовых+37discussionAPI, два браузерных имени, mobile320px, пагинация, повтор отправки, XSSplain text).


Дедлайны: календарная дата до конца дня по Москве, отдельный редактор и поле в форме задачи, подсветка просрочки, фильтры сроков, ближайшие сроки выше внутри группы. У старых задач даты не назначены автоматически: подтверждённых сроков в сохранённом источнике нет. Новый сервер сохраняет due_date при работе старого клиента; deadline/status/discussion не затирают друг друга. deadlines-v1 установлен с backup и проверкой сохранности данных.
