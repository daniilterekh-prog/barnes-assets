# BARN Estate — рабочая доска

Клиент мини-трекера, версия 1.0.0 от 19.10.2026.

[Открыть рабочую доску](https://daniilterekh-prog.github.io/barnes-assets/taskboard/).

Vanilla HTML/CSS/ES modules; внешних зависимостей и заимствованных UI-компонентов нет. В публичном клиенте нет задач, кодов доступа или серверных ключей. Данные доступны после входа по коду команды. Канонические исходники, сервер и документация — приватный barnes-sites/apps/taskboard.

Статусы общие для команды, имя выбирается при входе.
